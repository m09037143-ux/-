# Руководство пользователя

## Что это за программа

Программа автоматически формирует ежемесячный отчёт о выполненных ремонтах
(HTML, PDF, DOCX) на основе одного файла-выгрузки из вашей учётной системы —
без ручного пересчёта в Excel.

## Какой файл загружать

Загружайте **весь накопительный файл выгрузки** (`WR_Consolidated_List_*.xlsx`),
а не файл только за нужный месяц — и не какой-либо другой промежуточный или
сводный файл. Так работает программа с любым месяцем каждый раз.

**Почему именно весь накопительный файл, а не только новый месяц:**
колонки «Предыдущий период» и «Динамика» программа считает, сравнивая два
месяца из ЭТОГО ЖЕ файла (текущий и календарно предшествующий) — отдельной
базы истории программа не ведёт. Если приложить только один месяц, сравнение
будет недоступно, и программа честно об этом сообщит, а не покажет неверные
цифры.

## Как программа определяет период

Программа сама находит все месяцы, присутствующие в файле (по колонке
«Дата акта»), и по умолчанию выбирает последний (самый новый). Вы можете
выбрать другой месяц из списка, чтобы пересчитать отчёт задним числом —
программа заново найдёт для него предыдущий месяц в том же файле.

Если календарно предыдущий месяц отсутствует в файле — программа явно
покажет предупреждение «Календарно предыдущий месяц отсутствует в файле —
сравнение недоступно» вместо того, чтобы молча сравнить с более старым
периодом или показать пустые/неверные значения.

## Профиль заказчика

Реквизиты шапки отчёта (Исполнитель, Заказчик, номер и дата договора,
подписант) не хранятся в файле выгрузки — их нужно один раз занести в
профиль заказчика (кнопка «Новый / Редактировать…»). В следующие месяцы
просто выбирайте сохранённый профиль из списка.

## Раздел 10 — запасные части (второй файл)

Раздел 10 («Аналитика поставок запасных частей») строится из ОТДЕЛЬНОГО
файла — выгрузки по запасным частям из логистической/учётной системы, а
не из основного `WR_Consolidated_List_*.xlsx`. В окне программы для него
есть отдельное, равноценное окно загрузки — рядом с окном для основного
файла ремонтов, оба принимают перетаскивание файлов напрямую. Обычный
рабочий процесс: перетащить оба файла (в любом порядке), затем нажать
«Сформировать отчёт» — остальное программа делает сама.

Файл по запасным частям технически необязателен: если его не загрузить,
раздел 10 просто не показывается, а остальной отчёт формируется как
обычно.

Формула раздела подтверждена точно: программа берёт из файла запчастей
строки за ДВА месяца — выбранный текущий период и календарно предыдущий
(так же, как остальные разделы отчёта сравнивают «текущий/предыдущий»),
считает по дате отправки заказа. Если в загруженном файле запчастей нет
данных за нужные два месяца — раздел покажет предупреждение об этом, а не
нулевые/неверные цифры.

Раздел 10.2 «География поставок» определяет город/округ приближённо, по
тексту адреса доставки — для большинства городов совпадает с эталоном
точно, но для отдельных нестандартных адресов возможны небольшие
расхождения.

## Что означает «Показывать раздел 11»

Раздел 11 (техподдержка) по-прежнему требует данных, которых нет ни в
основном файле выгрузки, ни в файле запчастей, ни в промежуточном файле,
которым ранее пользовался подготовитель отчёта вручную — это подтверждено
проверкой. Поэтому по умолчанию этот раздел не показывается. Если вы
включите чекбокс «Показывать раздел 11», вместо цифр появится пометка о
том, что источник данных для этого раздела требует уточнения у заказчика —
так вы не получите правдоподобно выглядящие, но на самом деле неверные
цифры.

## Шаги работы

1. Перетащите файл `WR_Consolidated_List_*.xlsx` в левое окно (или нажмите
   «Выбрать файл…»).
2. Перетащите файл по запасным частям в правое окно, если хотите видеть
   раздел 10 — тогда в отчёте появятся реальные данные по нему.
3. Дождитесь, пока программа определит период — в выпадающем списке
   появится список найденных месяцев, по умолчанию выбран последний.
4. Выберите (или создайте) профиль заказчика.
5. Отметьте нужные форматы выгрузки (можно несколько сразу): HTML, PDF, DOCX.
6. Нажмите «Сформировать отчёт» и укажите папку для сохранения.

## Логи

Если что-то пошло не так, журнал работы программы сохраняется в
`%LOCALAPPDATA%\RepairReportApp\logs\app.log` — приложите этот файл при
обращении к разработчику.
